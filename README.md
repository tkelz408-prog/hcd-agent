# Human-Centred Design Agent

## Overview
This project demonstrates an AI agent built using Microsoft Foundry that translates user goals into:

- Operating models  
- Engagement strategies  
- Continuous feedback loops  

## Problem
Organisations struggle with low adoption due to poor onboarding, complex workflows, and lack of user-centric design.

## Solution
The agent uses embedded user insights (e.g. onboarding confusion, navigation challenges, and adoption drop-off) to generate structured, data-driven recommendations.

## Features
- Human-Centred Design recommendations  
- Structured outputs (operating model, engagement, feedback loops)  
- Insight-driven decision making
